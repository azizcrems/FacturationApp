# 📱 FacturationApp

Application Android développée en **Kotlin** permettant de gérer des articles, calculer automatiquement la TVA et le prix TTC, puis sauvegarder les données localement.

## 📖 Description

L'application permet à l'utilisateur de :

- Ajouter des articles avec leur libellé et leur prix HT ;
- Sélectionner un taux de TVA (5 %, 10 %, 15 % ou 20 %) ;
- Calculer automatiquement le prix TTC ;
- Afficher les articles dans un tableau ;
- Calculer le montant total TTC ;
- Sauvegarder les articles dans un fichier binaire ;
- Recharger automatiquement les données enregistrées.

## ✨ Fonctionnalités

- ✅ Ajout d'articles
- ✅ Calcul automatique de la TVA
- ✅ Calcul du prix TTC
- ✅ Affichage des articles dans un tableau
- ✅ Calcul du total TTC
- ✅ Validation des saisies
- ✅ Sauvegarde des données
- ✅ Chargement automatique des données

## 🛠️ Technologies utilisées

- Kotlin
- Android Studio
- Android SDK
- XML (Interface utilisateur)
- Serializable (Sauvegarde des données)

## 🚀 Installation

1. Cloner le dépôt :

```bash
git clone https://github.com/azizcrems/FacturationApp.git
```

2. Ouvrir le projet avec **Android Studio**.

3. Synchroniser Gradle.

4. Compiler puis exécuter l'application sur un émulateur ou un appareil Android.
